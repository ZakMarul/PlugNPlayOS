# # Welcome to PlugNPlayOS

___

- Documentation version: `v0.2`

## What is this project ?

- This project is a global nixos configuration for me, aka "Marul Zaknic", managing my systems and my home in nixos.

- It uses hyprland as a window manager and compositor, and personal quickshell config as a basic graphical shell. It is centered around **keyboard based control** and it uses **nvim** as its primary editor.

- It is a general purpose system with tools for dev, gaming and design.
